# Nexus Crucible (Minecraft 1.12.2 Expert Modpack)

**Nexus Crucible** — техно-магическая Expert-сборка с 11 стадиями прогрессии (`s00`–`s10`), обязательным чередованием технологий и магии, и масштабными крафтами 9×9.

- **Версия Minecraft:** 1.12.2
- **Загрузчик модов:** Minecraft Forge (рекомендуемый baseline: `14.23.5.2864` / `14.23.5.2860`)
- **Среда выполнения Java:** Java 8 (OpenJDK 8 x64)
- **Целевая длительность:** 300–500 часов
- **Стек скриптов:** CraftTweaker 2, ContentTweaker, ModTweaker, GameStages
